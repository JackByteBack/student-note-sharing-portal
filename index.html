Student Note Sharing Portal

A moderated study-notes library: students upload lecture notes (PDF/JPG/PNG, ownership attestation), moderators approve or reject every submission before it goes public, anonymous visitors can browse freely and download once logged in. Includes a public redacted transparency log, download/view counters, bookmarks and an analytics dashboard.

Heads-up: this page is the project hub, not the live app. The full app needs PHP + MySQL, which static/JavaScript hosts like Vercel don't provide — run it locally with XAMPP (3 steps below) or host the same files on any PHP hosting.

What it looks like

Run it locally in 3 steps

  1. Install XAMPP, copy the student-note-portal/ folder into htdocs/.
  2. Import the database: open phpMyAdmin → Import → note_portal.sql.
  3. Open http://localhost/student-note-portal/ and log in as admin@westfield.edu / admin123.
