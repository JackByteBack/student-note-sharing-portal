# Title: Student Note Sharing Portal — Content Guidelines

Status: Proposed (applied in moderation; wording still light)
Last updated: 2026-10-18

Uploads must be the uploader's own work or clearly sourced (attestation checkbox —
D-010). Code that enforces them, in review flow reason categories: copyright,
low_quality, duplicate, off_topic, abusive, privacy, other.

## Rules for students

1. Note must have a clear subject and be understandable without the lecture.
2. No personal data in screenshots (student IDs, others' names).
3. No exam-spoiler speculation (seed note 9 demonstrates a rejected case with reason `low_quality`).
4. No scraping from books/paid courses; scanned textbook chapters will be removed (`copyright`).

## Moderation response

Pre-moderation queue handles pending notes first (D-009). Published notes may be
removed later through the report inbox or the published list screenshot-removal form;
every action lands in the append-only audit and the public transparency log.
