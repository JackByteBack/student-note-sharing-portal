# Title: Student Note Sharing Portal — Glossary

Defines domain terms used across the project documents.

Status: Proposed
Last updated: 2026-10-18

Terms marked Proposed are working definitions until the owner confirms them.

| Term                | Definition                                                                    | Status         |
| ------------------- | ----------------------------------------------------------------------------- | -------------- |
| Note                | A shareable study file (e.g. PDF or image set) with metadata                  | Proposed       |
| Course              | Academic program or class a note belongs to                                   | Proposed       |
| Subject             | Topic within a course                                                         | Proposed       |
| Public visitor      | Anyone browsing without logging in                                            | Confirmed role |
| Student             | Logged-in user who uploads and downloads notes                                | Confirmed role |
| Teacher / moderator | User who reviews and moderates notes                                          | Confirmed role |
| Admin               | User with full management rights                                              | Confirmed role |
| Moderation queue    | List of notes awaiting review                                                 | Proposed       |
| Report              | A user flag that a note is wrong, abusive, or infringing                      | Proposed       |
| Transparency view   | Read-only view of admin-visible information for all users; scope Open (D-P01) | Open           |
| Note status         | One of: Draft, Pending, Published, Rejected, Removed                          | Proposed       |
| Audit log           | Append-only record of moderation and admin actions                            | Proposed       |
| Takedown            | Removal of a note after a copyright complaint                                 | Proposed       |
